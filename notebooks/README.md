# Signal Exploration Notebooks

Place exploratory Jupyter notebooks here for ad-hoc analysis.

Example notebooks to create:
- `01_signal_exploration.ipynb` — Visualize signal components for a single ticker
- `02_backtest_analysis.ipynb` — Deep-dive into backtest results
- `03_leaps_candidates.ipynb` — LEAPS candidate analysis

## Running Notebooks

```bash
uv run jupyter lab
```

(Add `jupyter` to dev dependencies if needed: `uv add --dev jupyter`)
